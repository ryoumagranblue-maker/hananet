# 花ネット 旧サイト再現デモ

2023年9月30日のWayback Machine保存ページを参照し、旧サイトの固定幅2カラム、左側の画像付きメニュー、見出し帯、送料案内、新入荷情報、商品一覧の密度を優先して再構成した静的デモです。

## ファイル
- `index.html` — 旧サイト風のページ構造
- `style.css` — 固定幅レイアウト、色、文字、サイドメニュー
- `app.js` — 検索、カテゴリ選択、商品追加、数量変更、カート、送料計算

## 実装
- 商品検索（商品名、分類、色、説明、商品番号）
- カテゴリ選択
- 価格順・商品名順ソート
- カートへの追加・数量変更・削除
- 配送先（本州・四国・九州／北海道／沖縄）
- 常温／クール便の送料計算、梱包数の指定
- 消費税10%の仮計算とデモ注文確認

## 復元精度について
- 旧サイトで確認できたカテゴリ、会員メニュー、購入規約、送料案内、新入荷情報の文言と配置を参考にしています。
- ピンポン菊、ガーベラ等のロットと税別価格は2023年9月29日の保存商品ページを参照しています。
- Wayback Machine上の元画像URLを利用していますが、保存されていない画像は表示されない場合があります。
- すべての旧画像・商品ページが復元できたわけではありません。代替画像や仮の商品データにはエラー時のフォールバックを設定しています。
- 仮設定の価格が含まれる商品はデモ用です。実際の販売価格ではありません。

## 公開方法
3ファイルとREADMEをGitHubリポジトリのルートにコミットし、Settings → Pagesで公開できます。ビルド工程は不要です。

## 注意
静的フロントエンドのみです。実際の会員登録、認証、注文保存、メール送信、在庫管理、決済は行いません。実運用にはサーバー側の安全な注文処理が必要です。
