# 花ネット再現デモ（やさしい現代風デザイン）

2023年9月30日のWeb Archive保存資料と、最初の花屋サイト案を参考にした静的デモです。旧サイトらしい左カテゴリメニュー、卸売・特価品の案内、商品一覧、送料案内を維持しつつ、淡いピンク・若草色・生成り色で花屋らしい柔らかい印象に整えています。

## ファイル
- `index.html`：ページ構造・案内文
- `style.css`：レイアウト・色・レスポンシブ表示
- `app.js`：商品検索、カテゴリ絞り込み、価格順、カート、数量変更、送料計算、デモ注文確認

## GitHubへの配置
4ファイルをリポジトリの同じフォルダに配置してください。`index.html` と `style.css` と `app.js` は同じ階層である必要があります。GitHub Pagesで公開する場合は、Settings → Pagesで公開元ブランチとフォルダを選択します。

## 注意
- 保存資料をもとにした再構成デモであり、元サイトの完全な復元ではありません。
- 商品画像は外部画像URLを利用しています。インターネット接続や提供元の仕様により表示が変わる場合があります。
- 表示価格や送料は保存資料を参考にしたデモ値です。正式な取引条件として使用しないでください。
- 注文確認はデモです。決済、会員認証、個人情報の送信、実際の受注処理は行いません。
