# 花ネット再現デモ（GitHub公開用）

旧 hananet.jp の Wayback Machine 保存ページ（2023年9月30日）を参考に、昔の店舗型レイアウトを残しながら、スマートフォン対応・商品検索・カート・送料計算を実装したフロントエンドデモです。

## ファイル構成

- `index.html` — ページ構造と各セクション
- `styles.css` — レイアウト、配色、レスポンシブ対応
- `app.js` — 商品データ、検索、カテゴリ、カート、送料・税計算

## 起動方法

1. ZIPを展開します。
2. `index.html` をブラウザで開きます。
3. GitHub Pagesを使う場合は、3ファイルをリポジトリのルートへコミットし、Repository Settings → Pages で公開元を設定します。

ビルドツールは不要です。Google FontsとUnsplashの画像を利用するため、インターネット接続がある環境を推奨します。

## 実装済みのデモ機能

- 商品検索（商品名・カテゴリ・説明・タグ）
- カテゴリ絞り込み
- 価格順・商品名順ソート
- 商品をカートへ追加
- カート内の数量変更・削除
- お届け先エリア別の常温便／クール便送料
- 梱包数を指定した送料計算
- 商品小計、送料、消費税（10%仮計算）、合計表示
- スマートフォン向けレスポンシブ表示
- デモ注文内容確認ダイアログ（注文・決済は行いません）

## 重要な注意

- 商品名・画像・価格の多くはデモ用です。旧サイトの掲載内容を完全に取得したものではありません。
- ピンポン菊160円、ガーベラ100円、アンスリューム3,500円は、保存資料内の過去の掲載価格を例示しています。現行価格ではありません。
- 送料は旧サイト保存資料の税抜表示を参考にしています。現在の送料・契約・配送条件を保証しません。
- 画像は外部のUnsplash画像URLです。旧サイトの画像そのものではありません。
- 現状は静的フロントエンドです。会員登録、ログイン、在庫管理、注文保存、メール通知、実決済はありません。
- 実運用には、サーバー側API、データベース、認証、CSRF対策、入力検証、レート制限、監査ログ、個人情報保護対応、決済事業者連携などが必要です。
- `mailto:example@example.com` は仮リンクです。公開前に正式な連絡先と規約に置き換えてください。
